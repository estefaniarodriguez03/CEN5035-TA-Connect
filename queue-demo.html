Queue status (from API): —

Open — students may join. Paused / Closed — join returns 409 (queue is paused / queue is closed). TAs change state with PATCH below.

    Queue management

    Must be logged in as a TA; on success, Queue ID field above is set to the new queue id.

    Queue actions

    SSE listens for: STUDENT_JOINED, STUDENT_LEFT, STUDENT_SERVED, STUDENT_UP_NEXT, ANNOUNCEMENT_SENT, QUEUE_UPDATED, QUEUE_STATE_CHANGED (payload: previous_status, status). Each data: line is the full JSON envelope (type, queue_id, payload).

    Queue state (TA only)

    PATCH /api/queues/:id/state — body {"status":"open"|"paused"|"closed"}

    Legacy POST /api/queues/:id/status with the same JSON still works; this page uses PATCH /state.

    Notifications: announcement API

    Manual smoke test: (1) Connect to /events. (2) As a student, Join — expect STUDENT_JOINED, QUEUE_UPDATED, and STUDENT_UP_NEXT with payload.student_id / position: 1 for whoever is at the front of the line. (3) As the queue-owning TA, send an announcement — expect ANNOUNCEMENT_SENT then QUEUE_UPDATED. (4) As TA, Next — expect STUDENT_SERVED then QUEUE_UPDATED; if someone is still waiting, STUDENT_UP_NEXT names the new person at position 1 only. (5) As TA, set Pause or Close — badge updates; SSE shows QUEUE_STATE_CHANGED then QUEUE_UPDATED. Try Join as a student → 409 with a clear message. Set Open again to allow joins.
